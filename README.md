#  Sales Performance Dashboard

# Project Overview
Created an interactive sales dashboard using Power BI to analyze revenue, product performance, and regional trends. The project focuses on transforming raw data into meaningful insights for business decision-making.

# Tools & Technologies
- Power BI  
- Excel  
- SQL (optional)  

 Dataset
- Sales dataset containing product, city, category, and monthly sales details.

# Key Features
- Total sales analysis  
- Sales by category (Laptop, Phone, Headphone)  
- Monthly sales trends  
- Sales by city  
- Top-performing sales representatives  
# Key Insights
- Certain products generate higher revenue  
- Sales vary across different cities  
- Monthly trends show peak sales periods  
- Top sales reps contribute significantly to revenue  



# Conclusion
This dashboard helps in understanding sales performance and supports data-driven business decisions.
